# EndNote DOI citations in Word

1. **Prepare a review copy.** Identify the requested DOCX. Find citation placeholders containing only DOI tokens, article URLs and separators, including mixed groups and text split across Word runs. Follow the URL resolution rules in the batch guide to identify article links and flag uncertain candidates. Add native yellow highlighting to the full candidate spans in a new DOCX. Verify that only the proposed spans gained highlighting, and compare text, cover, existing fields and images to the source. Record an ordered manifest with paragraph location, exact span, ordered identifiers or URLs, and file fingerprint. Link the review copy and report the candidate counts.
2. **Wait for user approval of the displayed ranges.** An initial request to cite does not approve a review copy that has not yet been shown. Reconcile any edits the user made against their approved ranges. Wait for approval before replacing placeholders or importing records.
3. **Verify the records.** Resolve article URLs to a DOI or PMID when available. Deduplicate by verified article identity, preserving every occurrence and group in the manifest. Prefer PubMed, then Crossref or the publisher. Require exact identifier agreement and record title, authors, year, journal, DOI or PMID, and evidence URL. Ask the user before using a near match or topical alternative. If any member of a group remains unresolved, keep the entire group yellow and continue with the verified groups.
4. **Insert and save separately.** Back up the intended EndNote library, reuse records matching the verified DOI or PMID, and import only missing verified records. Make a new DOCX from the approved copy. Use the library's actual record numbers and format each group together using the Word EndNote add-in. Default to numbered citations in first-appearance order, using Vancouver if available. Honor any specified style and report the style used. See [the batch workflow and checks](references/word-endnote.md).
5. **Verify the saved result.** Compare each citation field's location, verified identifier and membership to the manifest, check the bibliography, compare the cover and noncitation text, and inspect how citations display in Word. Report how many groups were converted and list each remaining yellow span with its DOI or URL and context. If any part of verification is unavailable, describe the limit. Deliver a clickable link to the new file.
