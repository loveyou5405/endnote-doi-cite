# Word and EndNote batch workflow

## Article URL resolution

- Recognize parenthesized groups containing DOI strings, DOI resolver URLs, PubMed or PMC article URLs, or direct publisher article URLs. Support mixed groups and full-width brackets. Parse balanced brackets so literal parentheses inside an identifier or URL do not truncate it. Do not split on punctuation inside a URL. Flag ambiguous boundaries for review.
- A DOI resolver URL supplies the DOI candidate. For PubMed and PMC URLs, retrieve the specific record using its PMID or PMCID and obtain its DOI if present. For a publisher URL, inspect the canonical article page or documented publisher metadata for the article DOI and title, then verify against PubMed or Crossref as available. For a PDF URL, use the associated article landing page or explicit article metadata to identify it. A valid PubMed record with no DOI can be verified and cited by exact PMID.
- Record the original URL and resolved identifiers. Use public HTTP(S) article pages and public metadata endpoints. Avoid submitting signed links, credentials, or private query parameters to third-party lookup services. Do not treat a publisher homepage, search result, login page, or unverified filename as an article identity. Keep inaccessible or ambiguous links yellow and request the DOI, PMID, or public article link.
- Map different URLs and DOI forms for the same verified article to one library record. If verification uses PMID alone, match the library accession number and verify the PMID in the stored citation metadata. Do not import a second record because the source URL differs.

## Insertion and checks

- Use the supported desktop computer-use tool for Word and EndNote. Verify the active filename, dialog and input focus before typing. The modeless Word Find dialog can lose focus when its owner is activated. If focus is uncertain, use precise document-level edits on a copy. A previous installation-specific capture repair is not part of this workflow.
- For large DOCX files, parse OOXML with support for large attributes. Compute spans on concatenated paragraph text, with offsets back to individual runs. When splitting a run, preserve its formatting and avoid duplicating embedded objects or breaks. Modify only required package parts. Verify the review copy against the source before showing it.
- For batch lookups, query PubMed ESearch with small OR batches of quoted DOI strings tagged [aid], then retrieve PubMed EFetch XML and verify each returned DOI against the requested key. Query Crossref or the publisher for remaining keys. Check for multiple records, corrections, and identifier mismatches before import. Use RIS with Unicode UTF-8 and the Reference Manager (RIS) filter if importing in bulk. After import, compare metadata including corporate author names, which RIS import can split incorrectly.
- Obtain the actual DOI-to-record-number mapping from an EndNote XML export or read-only library inspection. Do not infer numbers from the import order or edit the library database. On the new Word copy, replace only approved, verified spans with temporary citations in the form {Surname, Year #RecordNumber}. For a group, put each reference in the same braces separated by semicolons. Remove yellow only from converted ranges. For a small batch, direct insertion through the add-in is also suitable after confirming the exact selected range.
- In Word, run EndNote → Update Citations and Bibliography, then save. Select the intended library if prompted. If the library is locked, identify the instance that owns it, close its saved session if needed, and reopen through the Word prompt. Resolve any match dialog only with a verified DOI or PMID.
- Inspect saved DOCX fields. Count outer ADDIN EN.CITE fields separately from nested EN.CITE.DATA. EndNote metadata can appear inline or in base64 field data. Compare the verified identifiers and record-number membership of each field in document order. Check the generated bibliography. To compare body text, replace each approved converted span and its corresponding citation field with the same sentinel and exclude the generated bibliography. Compare image payloads, confirm all unresolved spans remain yellow, and inspect the cover and representative single and grouped citations in Word. Temporary strings alone do not count as completed fields.
